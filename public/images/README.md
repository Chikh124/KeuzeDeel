# Інструкція для завантаження зображень

## Де завантажити фото:

Завантажте 3 зображення для секції Platform Section в цю папку: `public/images/`

## Назви файлів:

1. **platform-01.jpg** - для "Easy to Integrate"
2. **platform-02.jpg** - для "Track and share experiments"  
3. **platform-03.jpg** - для "Build your own visualizations"

## Формат:

- Рекомендований формат: JPG або PNG
- Розмір: приблизно 800x600px або більше
- Розмір файлу: до 2MB кожне

## Примітка:

Якщо зображення не завантажені, буде показано градієнтний fallback з назвою секції.
